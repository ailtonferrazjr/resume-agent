# CLAUDE.md: Resume Agent

## Project Purpose

This is a career management system powered by Claude Code. It builds a rich career context through an onboarding interview, then uses that context to generate tailored resumes and cover letters for specific job descriptions.

The core asset is `docs/career_master_context.md`, a comprehensive file capturing your full career history, metrics, technical detail, and narrative framing. This file is the single source of truth for all generated documents.

---

## Getting Started

1. Clone the repo and run `npm install`
2. Open in Claude Code
3. Run `/onboard`, which interviews you to build your career profile
4. Start applying: `/intake`, `/tailor`, `/cover-letter`

## Resume Generation Workflow

When generating a resume for a specific JD:

1. **Read the JD carefully.** Identify required skills, seniority, domain, and what the company values.
2. **Read `docs/career_master_context.md`.** Pull the most relevant experiences, metrics, and technical details.
3. **Synthesize, don't copy.** The context file is a reference, not a copy-paste source. Rewrite into concise, punchy, impact-focused bullets.
4. **Tailor aggressively.** Every bullet must earn its place for this specific role. Drop irrelevant experience, elevate what matters.
5. **Review with `/resume-review`.** Catch AI writing patterns, validate content relevance, verify metrics framing.
6. **Generate .docx.** Run `npm run generate -- resumes/<slug>.md` to produce the formatted document.

## Writing Rules for Resume Content

### Anti-AI Voice (CRITICAL)

AI-generated text has recognizable patterns that recruiters can spot. All resume content MUST read like a human wrote it.

**Banned characters and patterns:**
- **Em-dash as sentence connector:** NEVER use "did X — resulting in Y". Replace with commas, periods, semicolons, "which", "and", or restructure. Exception: em-dash is OK in "Company — Role" title format only.
- **Banned words/phrases:** leverage, utilize, spearhead, delve, tapestry, multifaceted, synergy, paradigm, holistic, robust (non-technical), cutting-edge, state-of-the-art, seamlessly, game-changer, empower
- **Banned sentence structures:** "By doing X, achieved Y" (robotic inversion), "This resulted in..." (passive), excessive present participles ("...enabling, driving, fostering")

**What to do instead:**
- Write short, direct sentences. Subject-verb-object.
- Use commas and periods, not em-dashes, to connect ideas.
- One idea per bullet. If a bullet has two ideas, split it or pick the stronger one.
- Read it out loud. If it sounds like a LinkedIn post, rewrite it.

### Bullet Style
- Concise and punchy, no filler words, no passive voice
- Outcome-oriented: lead with impact, not activity
- Use frameworks: XYZ ("Accomplished X, as measured by Y, by doing Z"), STAR, or CAR
- Every bullet should pass the "so what?" test

### Metrics
- Always include quantified impact where available
- Round favorably; use the strongest credible framing
- Prefer gross/GMV figures over net when available
- Nothing that couldn't survive a technical interview

### Technical Detail
- For engineering roles: go deep on architecture and systems
- For product roles: emphasize ownership, cross-functional work, business outcomes
- For ops roles: emphasize process design, scale, efficiency
- Stack lines: only include technologies relevant to the target role

### Experience Order
- ALWAYS list in reverse chronological order (most recent first)
- NEVER reorder roles to match perceived relevance
- Tailor through bullet framing, not role ordering

## ATS & Formatting Guidelines

- Optimize for ATS parsing: clean headings, standard section names
- Two-page max for experienced roles; one-page for junior-targeted applications
- Per-application tailoring is the highest-leverage activity
- Mirror keywords from the JD naturally in bullet points and skills sections

## Tools & Automation

### gcloud CLI

Used for Google Drive integration (uploading .docx files). Setup via `/setup-gcloud`.

```bash
# List files in Drive folder
npm run upload -- --list

# Upload a specific file
npm run upload -- outputs/slug.docx

# Generate and upload in one step
npm run generate -- resumes/slug.md
```

### agent-browser

Used for LinkedIn and web scraping. Setup via `/setup-browser`.

```bash
agent-browser open <url>         # Navigate
agent-browser snapshot -i        # Get interactive element refs
agent-browser click @e1          # Interact using refs
agent-browser wait --load networkidle
agent-browser get-text           # Extract page text
```

### Application Tracker

Works out of the box using a local JSON file (`docs/tracker.json`). No setup required.

Optionally upgrade to Postgres for cloud-backed storage via `/setup-db`.

```bash
npm run tracker -- list                    # List all applications
npm run tracker -- add --company "X" --role "Y"  # Add manually
npm run tracker -- update --company "X" --stage "Applied"  # Update stage
```
